# 10 — Prompt inicial para o Codex

Leia o `AGENTS.md` e todos os documentos em `docs/specs`.

Implemente somente a Fase 0 de `docs/specs/09-planejamento-de-implementacao.md`.

Use uma única aplicação com:

- Next.js App Router;
- TypeScript;
- Tailwind CSS;
- shadcn/ui;
- Prisma;
- PostgreSQL;
- Zod.

Não use:

- Docker como requisito;
- monorepo;
- Fastify;
- backend separado;
- SQLite;
- microserviços;
- arquitetura excessivamente abstrata.

Antes de codificar:

1. inspecione o repositório;
2. resuma a arquitetura;
3. liste a estrutura que será criada;
4. identifique conflitos nas especificações;
5. crie o checklist da Fase 0.

Ao concluir:

1. execute lint e build;
2. execute testes existentes;
3. corrija os erros;
4. atualize somente o checklist da Fase 0;
5. informe arquivos criados e alterados;
6. informe comandos para executar o projeto;
7. registre decisões e pendências.

Não avance para a Fase 1.
